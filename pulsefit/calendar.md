## Rules

1. Today is a filled gold circle with black text.
2. Gold is the default category; add other categories only when they help scanning.
3. A cell shows three chips at most, then a gold "+N more".
4. Weekends use a barely warm tint, not gray.
5. The now line is red; no other element uses red in the grid.
6. Slots show their state by shape (filled, dashed, struck) as well as color.
7. Use the agenda view by default on narrow screens.
