# Staff

Staff examples for PulseFit, based on the structure of the reference agent-inspector screen by Nizam (https://x.com/nizamdesign/status/2106217679560355893): a floating top pill navigation, a header card with breadcrumb, big title and status pill, a visual "path" between two parties, a rounded-row comparison table with status chips, a side column of metric tiles, an analysis callout and related items. Rebuilt with PulseFit tokens: gold selected state, Bebas Neue titles, charcoal and gold-soft surfaces. Demo data is fictitious.

## Staff detail: shift handoff

The header shows the handoff between two coaches. The table compares what the outgoing coach passed on with what the incoming coach needs. Each row is a pill with a status chip; the row that matters is highlighted in gold-soft.

## Anatomy

| Part | Spec |
|---|---|
| Shell | White 20px-radius panel on the gray page, 12px gap between cards |
| Top navigation | Bebas Neue wordmark on charcoal, pill nav on a gray track, selected pill is gold with black text |
| Header card | Breadcrumb, Bebas Neue title with a soft status badge, one line of context |
| Path | Two raised nodes joined by a gold line with a metric pill (members, overlap, notes, items) |
| Comparison row | 12px-radius pill with a 1px hairline, mono-free Rubik labels, status chip on the right |
| Highlighted row | Gold-soft fill with a gold hairline |
| Metric tiles | Hairline tiles, label above a 20px value, two columns |
| Callout | Soft green for healthy, soft amber for caution, gold-soft for notes |
| Related items | Hairline rows with a status dot |
| Primary action | Pill in gray with bold text; the gold button is reserved for one action per view |

Rows use hairlines instead of shadows, so a long list stays quiet. Keep status as a chip with dark text on a tint.
