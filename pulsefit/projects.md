# Projects

Project dashboard examples for PulseFit, based on the structure of the project-management reference post by Marcel Kargul (https://x.com/marcelkargul/status/2105810012266512566): an icon rail, a project sidebar, a header with status, date and team, filters and a four-column Kanban board. Built with PulseFit tokens: charcoal rail, gold selected state, gold-soft highlights. Demo data is fictitious.

## Anatomy

| Part | Spec |
|---|---|
| Icon rail | Charcoal `#212529`, Bebas Neue mark in gold, selected icon is a gold square |
| Project sidebar | Gray-white panel, selected project in gold-soft with bold label, counts in muted text |
| Header | Bebas Neue title, status badge, due date, stacked team avatars, one gold primary button |
| Tabs | Underlined, selected tab has a gold underline |
| Filters | Pills; active is charcoal |
| Column | Page gray panel, bold heading with a count pill |
| Task card | White, 12px radius, 3px top rule by priority (red high, gold medium, sand low), category badge, due date, avatar |
| Dragged card | Rotated 1.5 degrees with the raised shadow |
| Detail | Raised card with checklist (gold check), progress bar and activity timeline |
