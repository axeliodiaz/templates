# Crestway financials

Light-gray acquisition and multi-branch financial dashboard. Revenue, EBITDA, margin, synergies and integration spend sit above actual-versus-plan bars, expandable shortfall drivers and a branch overtime report.

Source-inspired recreation from [the reference post](https://x.com/nizamdesign/status/2107265832296353798?s=4). Built with local components. Reference portraits are replaced with initials and illustrative controls. All financial figures, dates, payroll details and company names are sample content, not the user's accounts.

<CrestwayDashboard />

## Local interactions

Select companies and metrics, inspect monthly EBITDA, expand variance drivers and create local issues. The Issues tab lists demo-created entries. Other sections, favorites and company/team controls are illustrative. No real financial, payroll, company, tracker or messaging action occurs.

Charts and controls include motion; reduced-motion disables animation. Native dialogs support Escape. Layout stacks on narrow screens.
