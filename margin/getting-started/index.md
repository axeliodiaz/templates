# Introduction

Margin docs follow [Bootstrap 6.0](https://getbootstrap.com/docs/6.0/) section names with the `#6389ea` accent and AA analytics palette. Interactive previews stay inside `.lab` so VitePress prose never leaks Lustro styles.

## What you get

- **Components** — live catalog with copyable HTML per component page
- **Forms / Content** — scoped demos mapped from BS6
- **Customize** — `.lab` token swatches
- **Patterns** — `mg-*` analytics modules on [/margin/analytics](/margin/analytics)
