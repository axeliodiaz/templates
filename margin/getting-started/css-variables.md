# Css Variables

Lab tokens map into `--b2-*` Bootstrap variables inside `.b2-margin`:

```css
.lab {
  --bg: #f5f5f7;
  --surface: #fff;
  --ink: #22252b;
  --accent: #6389ea;
}
```
