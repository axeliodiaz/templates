Calendar examples for Felix, built from Felix tokens: white and linen surfaces, turquoise for the selected state, chart-series colors for categories. Follows the light/dark toggle. Demo data is fictitious; "today" in every demo is Wednesday, October 7, 2026.

## Anatomy

| Part | Spec |
|---|---|
| Header | Month or range title, previous/today/next controls, segmented view switcher (Day, Week, Month, Agenda) |
| Day cell | White cell, 1px `#cfcabf` rule (dark mode `#35605f`); day number top left, weekends tinted |
| Today | Filled circle on the day number, a turquoise `#2bf2f1` fill with ink text `#082422` |
| Selected day | Same fill on the number plus a turquoise cell outline |
| Event chip | Tinted fill from its category color, 3px left rule in the full color, 12px text, one line |
| Time grid | 48px per hour, event height equals duration, 2px gap between stacked events |
| Now line | 2px orange `#f26629` line with a dot on the left edge |
| Agenda row | Time, category bar, title, secondary line, attendee avatars |
| Availability | Row per person: free (empty), tentative (hatched), busy (solid); suggested slot outlined |

## Rules

1. One color per category, five at most. Never reuse a status color for a category.
2. Express state with shape: filled (all-day), dashed (tentative), struck through (declined), faded (cancelled).
3. Times in 12-hour or 24-hour format consistently within a view, never mixed.
4. Show "+N more" instead of growing a day cell past three chips.
5. Always mark today and the current time; selection never replaces them.
6. Weekends stay visible; tint them rather than hide them.
7. Conflicts are shown inline on the event, with a clear way to keep both or reschedule.
