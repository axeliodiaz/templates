# Pulse projects

Light lavender project-management dashboard with KPI sparklines, a project-health donut, active projects, recent activity, performance trends and quick actions.

Source-inspired recreation from [the reference post](https://x.com/IamMuhammadMuiz/status/2107495413095817615?s=46). Not the PulseFit fitness design. Initials replace the reference's portrait photos. Data is fictitious and historical dates are sample content, not current deadlines.

<PulseDashboard />

## Local interactions

Search and filter projects, open project details, change status/progress, compare reporting periods and create sample projects/tasks. Invite Team only prepares a local demo entry. No real message, account, subscription or workspace action occurs. Reloading resets changes.

Cards, charts and controls include motion. Reduced-motion preferences disable animation. Native dialogs support Escape; tables scroll on narrow screens.
